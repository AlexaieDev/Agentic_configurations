# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [3.0.0] - 2025-12

### Agregado
- **60+ nuevos agentes** cubriendo todo el ciclo de desarrollo de software
- **Nuevas categorías**: Backend, DevOps, Testing, Architecture, Data, Integrations
- **Agentes de Backend**: GraphQL, Message Queue, Caching Strategy, Search Engine, WebSocket & Real-time
- **Agentes de Arquitectura**: Event-Driven, DDD, Microservices, Clean Architecture, Monolith to Microservices
- **Agentes de Seguridad**: Authentication, Authorization, Secret Management, Vulnerability Management
- **Agentes de DevOps**: Infrastructure as Code, Container Orchestration, Service Mesh, CDN, Serverless, Multi-Cloud
- **Agentes de Testing**: Test Strategy, E2E Testing, Visual Regression, Load Testing, Contract Testing, Mutation Testing, A/B Testing
- **Agentes de Data**: Data Pipeline, Data Quality, ML Ops
- **Agentes de Integrations**: Payment Integration, Email Delivery, File Storage, Notification Hub
- **Agentes Transversales**: Code Review, Onboarding, ADR, Feature Flag, Logging Strategy, Error Handling, Configuration Management
- **Agentes Web**: Responsive Design, CSS Architecture, Animation & Motion, PWA, State Management, Micro-Frontend
- **Agentes Mobile**: App Store Optimization, Push Notification, Offline-First, Deep Linking
- **Documentación**: `COMO_USAR.md` con guía completa para VS Code + Claude Opus
- **Use case routing** en `index.json` para escenarios comunes
- **Recommended kits** para diferentes tamaños de equipo (startup, scaleup, enterprise)

### Cambiado
- Reorganización de categorías para mejor navegación
- Estructura de `index.json` mejorada con metadata adicional

### Corregido
- Referencias rotas en secciones COORDINA CON de 63 agentes
- Nombres genéricos reemplazados por nombres exactos de agentes
