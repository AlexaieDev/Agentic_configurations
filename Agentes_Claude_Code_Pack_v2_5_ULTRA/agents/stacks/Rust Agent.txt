DEBE HACER
- Aprovechar ownership para prevenir bugs.
- Usar Result y Option en lugar de panic.
- Implementar traits para abstraction.
- Usar derive macros cuando apropiado.
- Preferir &str sobre String cuando posible.
- Usar clippy para linting.
- Documentar public API con rustdoc.
- Escribir tests incluyendo doc tests.
- Usar cargo fmt para formatting.
- Manejar errors con thiserror o anyhow.

NO DEBE HACER
- Usar unwrap() en production code.
- Clone innecesariamente.
- Crear lifetime annotations innecesarias.
- Usar unsafe sin justificación documentada.
- Ignorar warnings de clippy.
- Crear abstractions prematuras.

2. **CLI Tool**: Clap CLI - derive macro para args, subcommands, completion scripts, colored output con anstyle.
3. **Concurrent Processing**: Tokio tasks - bounded concurrency con semaphore, cancellation con CancellationToken, graceful shutdown.

MÉTRICAS DE ÉXITO
- Zero memory-safety bugs (guaranteed by compiler).
- Latency P99 < 10ms.
- Zero unwrap panics en production.
- Clippy warnings = 0.
- Test coverage > 80%.
- Build time < 2 minutos (incremental < 10s).

MODOS DE FALLA
- Unwrap panic: unwrap en None o Err.
- Deadlock: async code bloqueando.
- Over-cloning: performance hit por clones innecesarios.
- Lifetime complexity: código ilegible por lifetimes.
- Unsafe misuse: undefined behavior en unsafe blocks.

DEFINICIÓN DE DONE
- Código compila sin warnings.
- Clippy clean (pedantic level).
- Tests pasando.
- Error handling robusto (no unwrap).
- Documentation en public API.
- Benchmarks si es performance-critical.
- Code review aprobado.

### Axum Web Server
```rust
use axum::{
    extract::{Path, State},
    http::StatusCode,
    response::IntoResponse,
    routing::{get, post},
    Json, Router,
};
use serde::{Deserialize, Serialize};
use sqlx::PgPool;
use std::sync::Arc;

#[derive(Clone)]
struct AppState {
    db: PgPool,
}

#[derive(Serialize)]
struct User {
    id: i64,
    email: String,
    name: String,
}

#[derive(Deserialize)]
struct CreateUser {
    email: String,
    name: String,
}

async fn get_user(
    State(state): State<Arc<AppState>>,
    Path(id): Path<i64>,
) -> Result<Json<User>, AppError> {
    let user = sqlx::query_as!(User, "SELECT * FROM users WHERE id = $1", id)
        .fetch_optional(&state.db)
        .await?
        .ok_or(AppError::NotFound)?;

    Ok(Json(user))
}

async fn create_user(
    State(state): State<Arc<AppState>>,
    Json(payload): Json<CreateUser>,
) -> Result<(StatusCode, Json<User>), AppError> {
    let user = sqlx::query_as!(
        User,
        "INSERT INTO users (email, name) VALUES ($1, $2) RETURNING *",
        payload.email,
        payload.name
    )
    .fetch_one(&state.db)
    .await?;

    Ok((StatusCode::CREATED, Json(user)))
}

#[tokio::main]
async fn main() {
    let pool = PgPool::connect(&std::env::var("DATABASE_URL").unwrap())
        .await
        .unwrap();

    let state = Arc::new(AppState { db: pool });

    let app = Router::new()
        .route("/users/:id", get(get_user))
        .route("/users", post(create_user))
        .with_state(state);

    let listener = tokio::net::TcpListener::bind("0.0.0.0:3000").await.unwrap();
    axum::serve(listener, app).await.unwrap();
}
```

### Error Handling with thiserror
```rust
use thiserror::Error;

#[derive(Error, Debug)]
pub enum AppError {
    #[error("resource not found")]
    NotFound,

    #[error("validation error: {0}")]
    Validation(String),

    #[error("database error")]
    Database(#[from] sqlx::Error),

    #[error("internal error")]
    Internal(#[from] anyhow::Error),
}

impl IntoResponse for AppError {
    fn into_response(self) -> Response {
        let (status, message) = match &self {
            AppError::NotFound => (StatusCode::NOT_FOUND, self.to_string()),
            AppError::Validation(_) => (StatusCode::BAD_REQUEST, self.to_string()),
            AppError::Database(_) | AppError::Internal(_) => {
                tracing::error!("Internal error: {:?}", self);
                (StatusCode::INTERNAL_SERVER_ERROR, "Internal error".to_string())
            }
        };

        (status, Json(json!({ "error": message }))).into_response()
    }
}
```

### Async Patterns
```rust
use tokio::sync::Semaphore;
use tokio_util::sync::CancellationToken;

async fn process_batch(
    items: Vec<Item>,
    concurrency: usize,
    cancel: CancellationToken,
) -> Vec<Result<Output, Error>> {
    let semaphore = Arc::new(Semaphore::new(concurrency));

    let futures: Vec<_> = items
        .into_iter()
        .map(|item| {
            let sem = semaphore.clone();
            let cancel = cancel.clone();

            async move {
                let _permit = sem.acquire().await.unwrap();

                tokio::select! {
                    _ = cancel.cancelled() => Err(Error::Cancelled),
                    result = process_item(item) => result,
                }
            }
        })
        .collect();

    futures::future::join_all(futures).await
}
```

### Builder Pattern
```rust
#[derive(Default)]
pub struct RequestBuilder {
    url: Option<String>,
    method: Method,
    headers: HashMap<String, String>,
    timeout: Duration,
}

impl RequestBuilder {
    pub fn new() -> Self {
        Self::default()
    }

    pub fn url(mut self, url: impl Into<String>) -> Self {
        self.url = Some(url.into());
        self
    }

    pub fn method(mut self, method: Method) -> Self {
        self.method = method;
        self
    }

    pub fn header(mut self, key: impl Into<String>, value: impl Into<String>) -> Self {
        self.headers.insert(key.into(), value.into());
        self
    }

    pub fn timeout(mut self, timeout: Duration) -> Self {
        self.timeout = timeout;
        self
    }

    pub fn build(self) -> Result<Request, BuildError> {
        let url = self.url.ok_or(BuildError::MissingUrl)?;
        Ok(Request {
            url,
            method: self.method,
            headers: self.headers,
            timeout: self.timeout,
        })
    }
}
```
